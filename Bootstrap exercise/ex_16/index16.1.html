What is position-fixed?

The position-fixed class positions an element relative to the viewport. It stays in place even when the page is scrolled.

Classes Used
  • position-fixed — fixes the element
  • bottom-0 — sticks to the bottom
  • start-0 — starts from the left edge
  • end-0 — stretches to the right edge
  • w-100 — full width
Other Fixed Positions
  • position-fixed top-0 — Fixed to the top
  • position-fixed bottom-0 — Fixed to the bottom
  • position-fixed top-0 end-0 — Fixed top-right corner
  • position-sticky top-0 — Sticky on scroll
