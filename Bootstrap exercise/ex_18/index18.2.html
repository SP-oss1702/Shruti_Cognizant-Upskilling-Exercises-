Bootstrap is a free, open-source CSS framework for building responsive, mobile-first websites. It includes HTML, CSS, and JavaScript components.

Bootstrap's grid system uses a 12-column layout built with flexbox. It allows you to create responsive layouts using col-* classes.

Bootstrap utilities are single-purpose CSS classes like m-3, text-center, d-flex that help you style elements without writing custom CSS.
